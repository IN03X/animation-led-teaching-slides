# Concrete Failure Cases And Repairs

These are diagnostic examples, not a demand to add all of their theory to every lesson.

| Failure | What a novice infers | Repair |
| --- | --- | --- |
| Correct equations but all equal-weight and a new formula layout each page | 'I do not know where I am or which formula matters' | One current object and one result; retain derivation; stable semantic ordering, flexible page geometry |
| Every page has a bold bottom result, but no returned process uses it | 'Every line is important; I forgot what we are doing' | Distinguish local support from main results; return with the one needed conclusion and use it |
| A route badge says spectrum, but local factors and their purposes are unknown | 'I know the chapter, not why I am seeing this formula' | Anchor in the known product/operation; select the missing factor; return with its value |
| Finished miniature plots appear as an overview without being constructed | 'Where did these pictures come from?' | First animate the same input through the complete process, then focus on known objects |
| Repeated zooms return to an unchanged map and immediately leave again | 'We keep moving but learning nothing' | Each return retains a qualified result at its origin; next action uses it |
| Computing bandwidth is treated as the whole meaning of the signal's spectrum | 'The frequency view is a disconnected width exercise' | Maintain s(t) <-> S(f); obtain the spectrum first, interpret bandwidth as one consequence |
| Receiver starts with M already recovered or introduces G/g without need | 'The answer appeared before the operation' | Start with the actual known s or sample stream; show read/select/gain/convolution before recovered m |
| Sinc responses move, but their centres and signs are not linked to samples | 'These are decorative curves' | Match source sample to centre/height, move then weight then add every signed response |
| Generic jargon like RF/IF appears before its operation | 'This is another difficult concept' | Show a selected frequency becoming a chosen receiver frequency, then name it |
| A transmitted signal is confused with the receiver's intermediate | 'The IF is what was sent' | Show the complete sender/channel/receiver path and introduce the intermediate at its local operation |
| Structural arrow morphs across page changes | 'The arrow is the subject' | Fixed structure; animate the relevant signal or term only |
| Source formula vanishes/reappears at a different location | 'This is a new expression' | Relocate the same established object deliberately; preserve identity and explain any contraction |
| Standalone equals sign appears first | 'I must remember unfinished syntax' | Complete expression per cognitive step; local term rewriting |
| Loop runs while students read solutions | Attention repeatedly leaves the answer | Static entry, click once, hold result; use a deliberate replay only when explicitly needed |
| Teacher has to walk over to point to a sample or edge | The plot cannot direct attention itself | Local pointer, selected point and matching height guide at the exact intended objects |
| Known first nine slides copied by redrawing them | Familiarity lost, extra regressions | Import real shape/media/theme/layout ancestry and preserve timing when requested |
| Sampling equality fs=2W presented unqualified | Arbitrary boundary tones always recover | Source condition plus endpoint qualification; use fs>2W for safely separated illustration |
| Three TDM slots but only T<Ts shown | Pulses may overlap despite claimed safe condition | T<Ts/3 next to the three-slot construction |
| 1/T called the first zero of S, or strict spectral support | Spectrum ends there | Mark it as first positive zero of pulse response H; tails and combined-spectrum zeros differ |
| Axis t/Ts with ticks Ts and2Ts | Dimensional inconsistency | Use unitless tick numbers for normalized axes, or label the axis t |
| All pulse parameters changed, arrow says 'changed amplitude' | No controlled comparison | Change only central sample, keep old outline faint |
| TDM arrow points to a generic middle row | Selected sample's origin/target unclear | Circles on actual source/target, matched dashed height guides, correctly angled gutter arrow |
| Dark center copy, pointer says copy at fs but points at a gray lobe | Label and emphasis disagree | Darken precisely the targeted copy |
| Replicated components labeled as the observed summed spectrum | Components visually overlap but seem not added | Label 'Copies of M(f)' for decomposition; show actual signed sum separately if needed |
| A source or filter delay/gain silently omitted | Correct-looking diagram depicts another receiver | Keep phase and coefficient; label magnitude-only/normalized plots explicitly |
| Hidden appendix contains all missing explanations | Teacher must interrupt flow; student cannot recover reasoning | Complete essential derivation where its result is first used |
| All long proofs are on the main operation sequence, or collected far away | 'I keep losing the process between calculations' | Supply a qualified supporting result when needed, place full proof immediately next, then rejoin the process |
| Global restart/previous-action/group changes look correct in static renders | Previously working animation rollback breaks across most pages | Preserve the accepted backend; test a click-start zoom sample natively before propagation; content/PNG equality is not a playback test |
| Valid slides but multiple notes masters not consistently registered | PowerPoint asks to repair | Normalize package-level notes masters and relationships, then re-import actual package |
| A numerical example becomes a general formula, introducing parameters without their object | 'Where did these extra letters come from?' | Define the general input/centre/parameter beside the known numerical object before substitution |
| A navigation target exists but skips the operation named on its button | The example jumps to a generalization that assumes unfinished work | Check each shortcut's semantic destination, including example vs general routes, in the actual package |
| A proof is complete in speaker notes but missing from visible states | Students can copy a result but cannot reproduce its key sign/factor | Put the essential bridge on the slide; notes do not count as student-visible reasoning |
| Multiplication beside a fraction looks like a mixed number | A correct intended calculation appears arithmetically false | Use explicit multiplication or parentheses at the intended audience's ambiguity points |
| A review freezes the PPT but copies source files while the author is revising | Later source intent is mistaken for the artifact actually reviewed | Bind findings to the PPT hash and rendered states; freeze final sources after authoring stops and verify them with a separate rebuild |

Do not confuse simple with shallow. The approved result remains mathematically complete because its operations are visible and its necessary steps are retained, not because mathematical work was removed.
